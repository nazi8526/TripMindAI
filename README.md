# TripMind AI in Iran 🇮🇷
### سامانه جامع و هوشمند گردشگری و برنامه‌ریزی سفر به ایران

این پروژه یک وبسایت مدرن، واقعی، کاملاً فارسی و واکنش‌گرا (RTL) است که با الهام از معماری، هنر و رنگ‌های اصیل ایرانی (سبز زمردی، طلایی گرم و کرم طبیعی) و منطبق بر طرح مرجع برای معرفی جاذبه‌های گردشگری سراسر ایران پیاده‌سازی شده است.

---

## 🌟 ویژگی‌های پیاده‌سازی‌شده

1. **زبان، فونت و ساختار راست‌چین (RTL):**
   - زبان پیش‌فرض کاملاً فارسی (`lang="fa"` و `dir="rtl"`).
   - تایپوگرافی زیبا با فونت محبوب **وزیرمتن (Vazirmatn)**.
   - طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ.

2. **صفحه اصلی (Home):**
   - بنر معرفی اصلی با شعار «ایران را جوری سفر کن که دوست داری؛ باقی مسیر را با هم می‌چینیم».
   - نوار جستجوی شناور هوشمند با فیلتر مبدأ، مدت، بودجه، علایق و دکمه جستجو با هوش مصنوعی.
   - ردیف ۵ قابلیت کلیدی: پیشنهاد مقصد هوشمند، اقامتگاه‌های مناسب، برنامه سفر اختصاصی، مقایسه وسایل نقلیه و محاسبه هزینه.
   - اسلایدر مقاصد محبوب ایران (اصفهان، شیراز، یزد، قشم، ماسوله، تبریز و...).
   - بخش مقایسه وسایل نقلیه (هواپیما، قطار، اتوبوس و خودرو شخصی).
   - کارت تعاملی تغییر شرایط برنامه سفر با هوش مصنوعی.
   - کتیبه تزئینی اسلیمی «ایران، سرزمین هزار رنگ، هزار داستان ...».

3. **صفحه مقاصد ایران (Destinations):**
   - پوشش کامل **۳۲ شهر توریستی شاخص ایران**:
     *تهران، اصفهان، شیراز، یزد، کاشان، قم، مشهد، نیشابور، تبریز، اردبیل، ارومیه، مراغه، رشت، ساری، گرگان، ماسوله، سنندج، کرمانشاه، همدان، خرم‌آباد، کرمان، بم، بندرعباس، قشم، کیش، چابهار، بوشهر، اهواز، شوش، دزفول، بیرجند، زاهدان.*
   - جستجوی هوشمند متنی نام شهر، استان یا جاذبه.
   - فیلتر بر اساس نوع جاذبه (تاریخی، طبیعت‌گردی، ساحلی، کویری، فرهنگی، زیارتی).
   - فیلتر بر اساس استان‌ها و پهنه‌های جغرافیایی ایران.
   - مرتب‌سازی بر اساس امتیاز، تعداد نظرات و الفبا.

4. **صفحه اختصاصی هر شهر (City Detail View):**
   دارای ۱۰ بخش جامع و مجزا مطابق الزامات:
   - تصویر بزرگ و چشم‌نواز
   - نام شهر و نام استان
   - معرفی کوتاه در ۳ تا ۵ خط
   - تاریخچه و پیشینه تاریخی
   - جاذبه‌های تاریخی و باستانی
   - جاذبه‌های طبیعی و شگفت‌انگیز
   - غذاهای محلی و سنتی اصیل
   - صنایع‌دستی و سوغات شاخص
   - فعالیت‌های پیشنهادی گردشگری
   - پیشنهادهای اقامت (هتل‌های لوکس، هتل‌های سنتی و اقامتگاه‌های بوم‌گردی)
   - دکمه برنامه‌ریزی مستقیم برای همان شهر و مشاهده نظرات مسافران.

5. **بخش نظرات گردشگران (Tourist Experiences):**
   - عنوان اختصاصی: «ایران از نگاه گردشگران».
   - ۳۲ کارت اختصاصی برای تمام شهرهای معرفی‌شده همراه با عکس، نام استان و معرفی سه خطی.
   - صفحات اختصاصی تجربه سفر هر شهر با حداقل ۳ نظر نمونه واقعی‌نما و داستانی.
   - شامل نام نمایشی، تاریخ سفر شمسی، امتیاز ستاره‌ای و برچسب واضح «نظر نمونه نمایشی».
   - بخش فقط-خواندنی بدون فرم ارسال (جهت حفظ ماهیت نمایشی و الهام‌بخش).

6. **برنامه‌ریز تعاملی سفر (Trip Planner):**
   - دریافت شهر مبدأ، مقصد، مدت سفر (۲، ۳، ۴ یا ۷ روز)، سطح بودجه، سبک سفر، وسیله نقلیه و علایق چندگانه.
   - تدوین جدول زمان‌بندی روزبه‌روز (صبح، عصر، شب و پیشنهاد غذای محلی).
   - ارائه تخمین هزینه، اقامتگاه متناسب با بودجه و سوغات.
   - امکان پرینت و ذخیره برنامه سفر.
   - درج نشان شفاف مبنی بر آزمایشی/الگوریتمی بودن مدل در نسخه پایه.

7. **صفحه نظر شما درباره سایت (Site Feedback):**
   - فرم اختصاصی شامل نام، موضوع، امتیاز، متن بازخورد و اعتبارسنجی زنده.
   - شبیه‌سازی ثبت موفق و اعلام وضعیت آزمایشی ذخیره‌سازی محلی.

8. **صفحه ارتباط با پشتیبانی (Support & Contact):**
   - فرم استاندارد تماس با تفکیک واحد (فنی، محتوا، همکاری).
   - نمایش راه‌های ارتباط مستقیم (تلفن، ایمیل، نشانی دفتر).
   - آکاردئون سوالات متداول (FAQ).

9. **راهنمای سفر (Travel Guide):**
   - جدول ماتریسی مقایسه وسایل نقلیه (هواپیما، قطار، اتوبوس، خودرو شخصی).
   - تقویم چهارفصل ایران و مقاصد برتر هر فصل.
   - شماره‌های اضطراری سراسری (۱۱۵، ۱۱۰، ۱۱۲، ۱۴۱) و اصول گردشگری مسئولانه.

## 💻 راهنمای نصب و اجرا در ویندوز و VS Code

### پیش‌نیازها:
- نصب [Node.js](https://nodejs.org) (نسخه 18 یا بالاتر)
- نرم‌افزار [Visual Studio Code](https://code.visualstudio.com)

### مراحل اجرا:

۱. پوشه پروژه را در **VS Code** باز کنید (`File -> Open Folder`).

۲. کلید‌های ترکیبی `Ctrl + ~` را فشار دهید تا ترمینال باز شود.

۳. وابستگی‌های پروژه را با دستور زیر نصب کنید:
```bash
npm install
```

۴. برای اجرای سرور محلی توسعه دستور زیر را وارد نمایید:
```bash
npm run dev
```

۵. مرورگر خود را باز کرده و به آدرس نمایش داده‌شده در ترمینال مراجعه کنید:
```
http://localhost:3000
```

۶. جهت خروجی نهایی پروداکشن:
```bash
npm run build
```
